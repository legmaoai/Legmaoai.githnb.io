# LEGMAO V3 — 商业挑战者

这是可本地打开的静态网站，包含首页、业务挑战领域、行业、示意案例、公司理念和业务挑战表单。

## 如何打开

1. 将 `LEGMAO-V3.zip` 解压到一个文件夹。
2. 打开文件夹里的 `index.html`。
3. 使用页面顶部语言菜单切换语言（共 12 种）。

网站使用原生 HTML、CSS 和 JavaScript，无需安装框架或运行构建命令。Google Fonts 只用于增强字体显示；断网时会回退到系统字体。

## 表单说明

挑战表单通过 FormSubmit 提交到 `legmao.ai@gmail.com`，不再依赖访客设备上的邮件应用。表单只在已发布的网站（HTTP/HTTPS）上工作；双击打开的本地 HTML 预览无法提交。首次提交会触发 FormSubmit 的邮箱验证邮件；网站所有者需要先在收件箱中点击验证链接，之后转发才会启用。表单提交需要联网。

FormSubmit 是第三方表单服务。其说明表示提交内容可能保留最多 30 天；页面已向访客说明这一点。

## 项目结构

- `index.html`：主页
- `solutions.html`：业务挑战领域
- `industries.html`：行业观察
- `case-studies.html`：明确标注的示意案例，不含虚构客户或业绩
- `company.html`：理念与原则
- `challenge.html`：业务挑战表单及联系方式
- `assets/`：集中管理的样式、脚本和多语言数据
